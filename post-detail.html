Aritmetika Sosial: Konsep Untung, Rugi, Diskon, & Bunga Tunggal

Pelajari cara menghitung transaksi jual-beli, menentukan persentase laba dan rugi, potongan harga (rabat), perhitungan bunga tabungan perbankan, hingga pemisahan tara, bruto, dan netto dalam kehidupan nyata.

A Harga Beli ($\text{HB}$) & Harga Jual ($\text{HJ}$)

Dalam aktivitas perdagangan, nilai barang ditentukan oleh harga beli (modal pengadaan) dan harga jual (nilai saat ditawarkan ke pembeli):

  • Harga Beli ($\text{HB}$): Uang yang dikeluarkan pedagang untuk membeli atau memproduksi barang dagangan (modal).
  • Harga Jual ($\text{HJ}$): Uang yang diterima pedagang dari hasil penjualan barang dagangan kepada konsumen.

B Kondisi Untung, Rugi, dan Impas

Kondisi transaksi bergantung pada perbandingan antara $\text{HJ}$ dan $\text{HB}$:

Kondisi Untung ($\text{HJ} > \text{HB}$)
$$\text{Untung } (U) = \text{HJ} - \text{HB}$$
$$\%U = \frac{U}{\text{HB}} \times 100\%$$

Persentase laba dihitung terhadap Harga Beli (modal).

Kondisi Rugi ($\text{HB} > \text{HJ}$)
$$\text{Rugi } (R) = \text{HB} - \text{HJ}$$
$$\%R = \frac{R}{\text{HB}} \times 100\%$$

Jika $\text{HJ} = \text{HB}$, maka pedagang mengalami kondisi Impas.

C Diskon (Rabat) & Harga Bersih

Diskon adalah potongan harga yang diberikan penjual saat pembeli melakukan transaksi:

$$\text{Besar Potongan Diskon} = \% \text{Diskon} \times \text{Harga Awal}$$ $$\text{Harga yang Harus Dibayar} = \text{Harga Awal} - \text{Besar Potongan}$$

D Bunga Tunggal Tabungan

Jika seseorang menabung modal sebesar $M$ di bank dengan suku bunga $p\%$ per tahun selama $t$ bulan:

$$B = M \times \frac{p}{100} \times \frac{t}{12}$$ $$\text{Total Tabungan Akhir} = M + B$$

E Bruto, Netto, dan Tara

Bruto (Berat Kotor) Isi + Pembungkus
Netto (Berat Bersih) Murni Isi Saja
Tara (Potongan Berat) Wadah / Kemasan
$$\text{Netto} = \text{Bruto} - \text{Tara}, \quad \% \text{Tara} = \frac{\text{Tara}}{\text{Bruto}} \times 100\%$$

3 Butir Soal
Soal Nomor 1 Topik: Untung & Persentase

Pak Ahmad membeli $1$ lusin buku tulis seharga $\text{Rp } 36.000$. Buku tersebut kemudian dijual kembali secara eceran dengan harga $\text{Rp } 3.600$ per buah. Berapakah persentase keuntungan yang diperoleh Pak Ahmad?

Kunci Jawaban: B ($20\%$)

Langkah 1: Hitung harga beli per buah buku:

$$\text{HB per buah} = \frac{\text{Rp } 36.000}{12} = \text{Rp } 3.000$$

Langkah 2: Tentukan besar keuntungan per buah:

$$\text{Untung } (U) = \text{HJ} - \text{HB} = 3.600 - 3.000 = \text{Rp } 600$$

Langkah 3: Hitung persentase laba terhadap modal ($\text{HB}$):

$$\%U = \frac{U}{\text{HB}} \times 100\% = \frac{600}{3.000} \times 100\% = 20\%$$
Soal Nomor 2 Topik: Diskon Belanja

Sebuah jaket di toko bertuliskan label harga $\text{Rp } 250.000$ dengan potongan diskon sebesar $20\%$. Berapakah total uang yang harus dibayarkan pembeli di kasir?

Kunci Jawaban: C ($\text{Rp } 200.000$)

Cara Cepat: Pembeli hanya membayar persentase bersih $(100\% - 20\% = 80\%)$:

$$\text{Potongan} = 20\% \times \text{Rp } 250.000 = \text{Rp } 50.000$$ $$\text{Harga Bayar} = \text{Rp } 250.000 - \text{Rp } 50.000 = \text{Rp } 200.000$$
Soal Nomor 3 Topik: Bruto & Tara

Satu karung beras memiliki bruto sebesar $50\text{ kg}$ dengan tara $1{,}5\%$. Berapakah berat netto beras tersebut?

Kunci Jawaban: B ($49{,}25\text{ kg}$)

Langkah 1: Hitung berat tara (karung pembungkus):

$$\text{Tara} = \frac{1{,}5}{100} \times 50\text{ kg} = 0{,}75\text{ kg}$$

Langkah 2: Kurangkan tara dari bruto untuk mendapat netto:

$$\text{Netto} = \text{Bruto} - \text{Tara} = 50\text{ kg} - 0{,}75\text{ kg} = 49{,}25\text{ kg}$$
